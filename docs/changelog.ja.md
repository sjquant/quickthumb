## 0.8.0 — 2026-10-28 { #080-2026-10-28 }

- Canvas/Deck共通の出力レポート、基準サンプル、厳密なJSON、構造化された診断を追加しました。
- モーション、テキスト選択、パス、マスク、透過動画、対応範囲を限定したLottie出力を拡張しました。
- プレゼンテーション・検査・発表者のUIを統一し、アセットやフォントの再現性レポートとセキュリティ更新を追加しました。

互換性を破る変更を含む、1.0より前のリリースです。0.7.0から更新する前に、[リリースノートと移行例](releases/0.8.0.md)を読んでください。
