## 0.8.0 — 2026-10-28 { #080-2026-10-28 }

- 提供统一的 Canvas/Deck 导出报告、规范样本、严格的 JSON 校验与结构化诊断。
- 扩充了动效系统、文本选择器、路径、蒙版、透明视频以及受限的 Lottie 导出。
- 整合了演示文稿、文档检查与演讲者 UI，新增可复现的资源/字体报告与安全更新。

这是一个包含破坏性变更的 1.0 预览版本。从 0.7.0 升级前，请仔细阅读[完整发行说明与迁移示例](releases/0.8.0.md)。
