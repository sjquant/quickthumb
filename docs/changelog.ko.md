# 변경 기록 { #changelog }

릴리스 노트는 GitHub Releases에 게시됩니다.

## 0.8.0 — 2026-10-28 { #080-2026-10-28 }

- Canvas/Deck 공통 내보내기 결과, 정규 표본, 엄격한 JSON, 구조화된 진단을 제공합니다.
- 모션, 텍스트 선택기, 경로, 마스크, 투명 동영상, 제한된 Lottie 내보내기를 확장했습니다.
- 프레젠테이션·검사·발표자 UI를 통합하고 재현 가능한 에셋·글꼴 보고와 보안 업데이트를 추가했습니다.

1.0 이전 버전으로 호환성을 깨는 릴리스입니다.
0.7.0에서 업그레이드하기 전에 [전체 릴리스 노트와 마이그레이션 예제](releases/0.8.0.md)를 읽으세요.
