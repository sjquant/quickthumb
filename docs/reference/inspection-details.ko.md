# 복잡한 레이아웃 검사 { #inspecting-complex-layouts }

일반 검사 API는 [Canvas 검사](../api/canvas.md#inspect)와 [문서 검사](../api/inspection.md)를 참고하세요.

## 부모로 연결된 장면 { #parent-linked-scenes }

부모와 자식으로 연결된 장면을 검사하거나 `canvas.diagnose()`를 실행하면 다음 규칙에 따라 경계를 측정합니다.

- **제작된 정적 경계**: 레이어 경계 상자는 월드 공간의 정적 레이아웃 좌표를 설명합니다.
- **Null 컨트롤러**: `Canvas.null()`은 화면에 그려지지 않는 변환 기준점입니다. 눈에 보이는 영역이 없으므로 경계 상자도 만들지 않습니다.
- **시각적 디버그 오버레이**: `canvas.render("debug.png", debug=True)`로 각 레이어에서 측정한 정확한 경계 상자를 확인하세요.

## 그룹과 잘린 경계 { #groups-and-clipped-boundaries }

- **그룹 경계 상자**: 그룹의 측정 경계는 간격, 안쪽 여백, 연결된 클립·마스크를 반영해 모든 자식을 감쌉니다.
- **중첩 클립과 마스크**: 부모 그룹이나 하위 레이어에 적용한 클립·마스크는 상대 레이아웃 좌표를 바꾸지 않고 보이는 영역을 제한합니다.
- **숫자 애니메이션**: 내장 카운터 텍스트 레이어(`Canvas.counter()`)는 최종 정착 값으로 경계를 계산해 재생 중 레이아웃을 안정적으로 유지합니다.
