# 複雑なレイアウトの検査 { #inspecting-complex-layouts }

基本的な検査APIは[Canvasの検査](../api/canvas.md#inspect)と[ドキュメントの検査](../api/inspection.md)を参照してください。

## 親子関係のあるシーン { #parent-linked-scenes }

親子階層を検査するときや`canvas.diagnose()`を実行するときは、次の規則が適用されます。

- **作成時の静的な境界**：レイヤーのバウンディングボックスは、静的レイアウトのワールド座標を表します。
- **Nullコントローラー**：`Canvas.null()`レイヤーは目に見えない変換の基準点となり、視覚的なバウンディングボックスを作りません。
- **デバッグ表示**：`canvas.render("debug.png", debug=True)`で、各レイヤーについて測定した正確なバウンディングボックスを表示できます。

## グループとクリッピングの境界 { #groups-and-clipped-boundaries }

- **グループのバウンディングボックス**：間隔、余白、適用されたクリップやマスクを考慮し、すべての子を囲みます。
- **入れ子のクリップとマスク**：親グループや子孫レイヤーへのクリップ・マスクは、相対的な配置座標を変えずに表示領域を制限します。
- **アニメーションカウンター**：内蔵のカウンターテキストレイヤー（`Canvas.counter()`）は、最終的に落ち着く値で境界を計算し、再生中もレイアウトを安定させます。
