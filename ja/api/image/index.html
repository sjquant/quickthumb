    画像

    .image()は位置を指定した画像を重ねます。ローカルファイル、リモートURL、背景除去、フィット、ブレンド、エフェクトに対応します。

    シグネチャ

    canvas.image(
    path,
    position,
    width=None,
    height=None,
    fit=None,
    opacity=1.0,
    rotation=0.0,
    align=Align.TOP_LEFT,
    remove_background=False,
    border_radius=0,
    blend_mode=None,
    effects=None,
)

    パラメーター

    パラメーター 型 既定値 説明
    path str 必須 ローカルパスかリモートのhttp(s):// URLです。
    position tuple 必須 (x, y)位置。整数（ピクセル）か百分率文字列（"50%"）です。
    width int \| None None 目標幅（ピクセル）。片方の寸法だけなら縦横比を維持します。
    height int \| None None 目標高さ（ピクセル）。片方の寸法だけなら縦横比を維持します。
    fit str \| FitMode \| None None widthとheightの両方を指定したときの合わせ方。FitModeを参照してください。
    opacity float 1.0 0.0から1.0までの不透明度です。
    rotation float 0.0 回転角（度）です。
    align str \| Align \| tuple Align.TOP_LEFT 画像のどの点をpositionに合わせるか。Alignを参照してください。
    remove_background bool False AIで背景を除去します。quickthumb[rembg]が必要です。
    border_radius int 0 角の丸み（ピクセル）。0以上の整数です。
    blend_mode str \| BlendMode \| None None 合成のブレンドモード。BlendModeを参照してください。
    effects list \| None [] Stroke、Shadow、Glow、Filter、Grainのリストです。

    例

    基本の重ね合わせ

    canvas.image(
    path="portrait.png",
    position=("74%", "54%"),
    width=420,
    height=520,
    fit="cover",
    align=("center", "middle"),
)

    エフェクトを付ける

    from quickthumb import Filter, Shadow

canvas.image(
    path="portrait.png",
    position=("74%", "54%"),
    width=420,
    height=520,
    fit="cover",
    align=("center", "middle"),
    border_radius=28,
    effects=[
        Filter(contrast=1.1, saturation=1.05),
        Shadow(offset_x=0, offset_y=12, color="#000000", blur_radius=24),
    ],
)

    背景を除去する

    canvas.image(
    path="portrait.jpg",
    position=("75%", "55%"),
    width=430,
    height=540,
    align=("center", "middle"),
    remove_background=True,
)

    補足

    remove_background=TrueにはPython 3.11以降とuv pip install "quickthumb[rembg]"が必要です。初回にONNXモデル（約170 MB）をダウンロードしてキャッシュします。

    リモート画像

    canvas.image(
    path="https://example.com/avatar.png",
    position=("50%", "50%"),
    width=300,
    height=300,
    align=("center", "middle"),
    border_radius=150,  # circle
)

    縦横比を保つ

    # Only width: height keeps the image's proportions
canvas.image(path="logo.png", position=(40, 40), width=200)

# Only height: width keeps the image's proportions
canvas.image(path="logo.png", position=(40, 40), height=80)

    フィットモード

    fitはwidthとheightの両方がある場合に適用します。

    値 動作
    "cover" 枠を埋め、必要ならはみ出す部分を切り取ります。
    "contain" 画像全体を枠内に収め、端に余白を残します。
    "fill" 縦横比を無視し、枠にぴったり合うように引き伸ばします。

    検証規則

    • pathとpositionは必須です。
    • positionは2要素のタプルです。百分率文字列は-?N%形式です。
    • border_radiusは0以上です。
    • opacityは0.0から1.0の範囲です。
    • 無効なpathやリモートダウンロードの失敗は、描画時にRenderingErrorになります。
