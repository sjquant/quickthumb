    テキスト

    .text()はテキストレイヤーを追加します。内容には通常の文字列か、区間ごとに書式を指定するTextPartのリストを使えます。

    シグネチャ

    canvas.text(
    content,
    font=None,
    font_source="auto",
    font_variations=None,
    emoji_style="monochrome",
    size=None,
    color=None,
    fill=None,
    position=None,
    align=None,
    bold=False,
    italic=False,
    weight=None,
    max_width=None,
    max_height=None,
    min_size=1,
    balance_lines=False,
    effects=None,
    line_height=None,
    letter_spacing=None,
    auto_scale=False,
    rotation=0.0,
    opacity=1.0,
)

    パラメーター

    パラメーター 型 既定値 説明
    content str \| list[TextPart] 必須 通常の文字列か、リッチテキスト用のTextPartリストです。
    font str \| None None ファミリー名、ローカルパス、リモートのWebフォントURLです。
    font_source "auto" \| "system" \| "google" "auto" 検索元。"google"は指定したGoogle Fontを読み込み、キャッシュします。
    font_variations dict[str, float] \| None None {"wght": 650}などOpenTypeの可変軸の値です。
    emoji_style "monochrome" \| "color" "monochrome" 絵文字の表示方式です。
    size int \| None None 文字サイズ（ピクセル）。正の整数です。
    color str \| None None 既定の文字色。16進文字列（"#RRGGBB"、"#RRGGBBAA"）です。
    fill LinearGradient \| RadialGradient \| TextFillImage \| None None グリフのグラデーション・画像による塗り。指定時はcolorより見た目で優先されます。グラデーションと画像の塗りを参照してください。
    position tuple \| None None (x, y)位置。整数（ピクセル）か百分率文字列（"50%"）です。
    align str \| Align \| tuple \| None None テキストブロックの整列。Alignの値を参照してください。
    bold bool False 太字の指定。weightとは同時に使えません。
    italic bool False 斜体の指定です。
    weight int \| str \| None None CSS方式の太さ（700、900、"bold"など）。boldとは同時に使えません。
    max_width int \| str \| None None 折り返す幅。ピクセルか百分率文字列（"60%"など）です。
    max_height int \| str \| None None ブロックの最大高さ。ピクセルか百分率文字列です。
    min_size int 1 自動縮小時に許容する最小文字サイズです。
    balance_lines bool False max_widthがある場合に行の長さを均等にします。
    effects list \| None [] Stroke、Shadow、Glow、Backgroundのリストです。
    line_height float \| None None 行の高さの倍率。正の実数です。
    letter_spacing int \| None None 横方向の字間調整（ピクセル）です。
    auto_scale bool False max_widthやmax_heightに収まるまで文字を縮小します。
    rotation float 0.0 回転角（度）です。
    opacity float 1.0 0.0から1.0までの不透明度です。

    Alignの値

    alignには次の形式を使えます。

    align="center"              # shorthand
align="top-left"            # compound string
align=("left", "middle")    # (horizontal, vertical) tuple
align=Align.BOTTOM_RIGHT    # enum
    文字列 列挙型 位置
    "center" Align.CENTER 縦横とも中央
    "left" Align.LEFT 左揃え、縦は中央
    "right" Align.RIGHT 右揃え、縦は中央
    "top-left" Align.TOP_LEFT 左上
    "top-center" Align.TOP_CENTER 上辺の中央
    "top-right" Align.TOP_RIGHT 右上
    "bottom-left" Align.BOTTOM_LEFT 左下
    "bottom-center" Align.BOTTOM_CENTER 下辺の中央
    "bottom-right" Align.BOTTOM_RIGHT 右下

    タプルの横方向はleft、center、right、縦方向はtop、middle、bottomです。

    例

    通常のテキスト

    canvas.text(
    content="Hello World",
    size=64,
    color="#FFFFFF",
    align="center",
)

    TextPartで書式を分ける

    from quickthumb import Stroke, TextPart

canvas.text(
    content=[
        TextPart(text="5 ", color="#FBBF24", weight=900),
        TextPart(text="WARNING SIGNS", color="#FFFFFF", weight=900),
    ],
    size=72,
    position=("8%", "55%"),
    align=("left", "middle"),
)

    エフェクトを加える

    from quickthumb import Background, Glow, Shadow, Stroke

canvas.text(
    content="BREAKING",
    size=96,
    color="#FFFFFF",
    position=("8%", "50%"),
    align=("left", "middle"),
    weight=900,
    max_width="65%",
    effects=[
        Stroke(width=4, color="#000000"),
        Shadow(offset_x=4, offset_y=4, color="#000000", blur_radius=8),
        Glow(color="#B8FF00", radius=16, opacity=0.25),
        Background(color="#111827CC", padding=(16, 24), border_radius=14),
    ],
)

    枠に収まるよう縮小する

    canvas.text(
    content="This is a very long title that should fit",
    size=80,
    color="#FFFFFF",
    max_width="70%",
    auto_scale=True,
    position=("8%", "50%"),
    align=("left", "middle"),
)

    Webフォントを使う

    canvas.text(
    content="Custom Font",
    font="https://fonts.gstatic.com/s/inter/v13/UcCO3FwrK3iLTeHuS_fvQtMwCp50KnMw2boKoduKmMEVuLyfAZ9hiA.woff2",
    size=72,
    color="#FFFFFF",
    align="center",
)

    WebフォントのURL

    fontがURLなら特定のファイルを指すため、bold、italic、weightは無視します。スタイルごとに別のURLを使うか、ファミリー名とfont_source="google"を指定してweightとitalicでファイルを選んでください。

    グラデーションと画像の塗り

    単色の代わりにグラデーションや画像で文字を塗ります。fillへLinearGradient、RadialGradient、TextFillImageを渡します。

    from quickthumb import Canvas, LinearGradient, RadialGradient, TextFillImage, TextPart

# Linear gradient headline
canvas.text(
    content="GRADIENT",
    size=120,
    fill=LinearGradient(angle=90, stops=[("#FF6B6B", 0.0), ("#4ECDC4", 1.0)]),
    position=("50%", "50%"),
    align="center",
)

# Image-filled text
canvas.text(
    content="TEXTURE",
    size=140,
    fill=TextFillImage(path="fire_texture.jpg", fit="cover"),
    position=("50%", "50%"),
    align="center",
)

# Per-segment fills using TextPart
canvas.text(
    content=[
        TextPart(
            text="HOT ",
            fill=LinearGradient(angle=45, stops=[("#FF4500", 0.0), ("#FFD700", 1.0)]),
            weight=900,
        ),
        TextPart(
            text="COLD",
            fill=LinearGradient(angle=45, stops=[("#00BFFF", 0.0), ("#8A2BE2", 1.0)]),
            weight=900,
        ),
    ],
    size=110,
    position=("50%", "50%"),
    align="center",
)

    TextPartのfillは、その区間だけレイヤーのfillを上書きします。fillとcolorは独立しており、fillを指定すると見た目では優先されます。画像の塗りのオプションはTextFillImageを参照してください。

    TextPart

    TextPartはテキストレイヤー内の区間ごとに書式を設定します。

    from quickthumb import Stroke, TextPart

TextPart(
    text="HOT",
    color="#FF3B30",
    fill=None,
    size=56,
    font="Impact",
    font_source=None,
    font_variations=None,
    emoji_style=None,
    weight=900,
    italic=False,
    line_height=None,
    letter_spacing=0,
    effects=[Stroke(width=3, color="#000000")],
)
    パラメーター 型 既定値 説明
    text str 必須 区間の文字列。空にはできません。
    color str \| None None この区間の16進色を上書きします。
    fill LinearGradient \| RadialGradient \| TextFillImage \| None None この区間のグラデーション・画像の塗り。その区間だけレイヤーのfillを上書きします。
    size int \| None None この区間の文字サイズです。
    font str \| None None この区間のフォントです。
    font_source "auto" \| "system" \| "google" \| None None Noneならレイヤーを継承し、明示値なら上書きします。
    font_variations dict[str, float] \| None None Noneなら継承し、{}なら継承した可変軸を明示的に消します。
    emoji_style "monochrome" \| "color" \| None None Noneなら継承し、"monochrome"なら明示的に上書きします。
    bold bool \| None None 太字の上書き。weightとは同時に使えません。
    italic bool \| None None 斜体の上書きです。
    weight int \| str \| None None 太さの上書き。boldとは同時に使えません。
    line_height float \| None None 行の高さの倍率です。
    letter_spacing int \| None None 字間の上書きです。
    effects list[TextEffect] [] 区間専用のStroke、Shadow、Glow、Backgroundです。

    テキストのアニメーション

    RangeSelectorで単語単位や文字単位に動かせます。

    from quickthumb import AnimationSpec, Canvas, KeyframeSpec, PositionTrack, RangeSelector, TimingSpec

canvas = Canvas(800, 400).text(
    "Words appear one by one",
    size=48,
    color="#FFFFFF",
    position=(50, 150),
    animation=AnimationSpec.timeline(
        PositionTrack(keyframes=[
            KeyframeSpec(time=0, value=(0, 20)),
            KeyframeSpec(time=0.4, value=(0, 0)),
        ]),
        selector=RangeSelector(
            target="words",  # "words", "lines", or "characters"
            offset=[KeyframeSpec(time=0, value=-100), KeyframeSpec(time=2, value=100)],
        ),
        timing=TimingSpec(duration=2),
    ),
)

    選択の形、タイミング、色の変化はテキスト範囲の選択を参照してください。

    検証規則

    • contentは必須で、空のリストにはできません。
    • TextPart.textは空文字列にできません。
    • TextLayerとTextPartでweightとbold=Trueは同時に使えません。
    • auto_scale=Trueにはmax_widthかmax_heightが必要です。
    • max_widthは正の整数か"60%"のような正の百分率文字列です。
    • positionの百分率文字列は-?N%形式です。負の百分率も有効です。
    • fillとcolorは独立し、両方あればfillが見た目で優先されます。
    • TextFillImage.pathはローカルパスとリモートURLに対応します。ローカルファイルがなければ描画時にFileNotFoundErrorになります。
